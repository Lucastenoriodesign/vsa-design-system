# webdesigner

**Nicho:** Portfólio de web designer

**Linguagem visual:** Preto-azulado + violeta, ícones 3D vítreos, arco de luz horizonte.

**Estrutura observada:** Hero com arco luminoso; cards com ícones 3D; seções feature com imagem 3D; comparação eu vs outros; trabalhos; formulário de orçamento.

**Padrões reutilizáveis:**
- arco de luz horizonte
- comparação nós vs outros
- ícones 3D vítreos
