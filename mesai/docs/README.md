# Mesaí — entrega para Claude Code

Este pacote contém o site publicado (HTML, CSS e JS em site/index.html, com assets locais), uma versão em arquivo único mesai-autonomo.html e orientações de continuidade.

## Abrir o app

Extraia o ZIP. Abra mesai-autonomo.html no navegador (as imagens já estão embutidas). Para desenvolvimento, prefira site/index.html com um servidor local: `python3 -m http.server 8000 --directory site`, e abra http://localhost:8000.

Não há instalação de dependências nem build obrigatório. O app é HTML/CSS/JavaScript puro.

## Começar com Claude Code

Leia CLAUDE.md e REQUISITOS.md. Use site/index.html como fonte da implementação; não edite mesai-autonomo.html como fonte principal. Esse arquivo é uma cópia portátil para apresentação.
