# Ver o Mesaí ao vivo num iPhone, ao lado do Claude Code

1. No Claude Code (pasta `mesai`), peça: **"rode o modo ao vivo em segundo plano"** — ou rode `./dev/ao-vivo.sh`.
2. Abre `dev/iphone.html` no navegador: um iPhone com o app de `v2/` rodando em http://localhost:8124.
3. Toda vez que o Claude Code salvar um arquivo, o app dentro do iPhone recarrega sozinho.
4. Lado a lado no Mac: passe o mouse no botão verde da janela do Terminal › **Lado esquerdo da tela**; escolha o navegador para o lado direito.

Botões: trocar o modelo de iPhone, recarregar, e "Primeiro acesso" (mostra as boas-vindas de novo).
